# CON-2: The bootstrap problem

*"Just build a warp drive" is not a plan.*

**Kind:** constraint · **Family:** CON (Control) · **Last reviewed:** 2026-09-12

## The result

The bootstrap problem. Krasnikov: the traveller cannot hasten reaching the destination on a first flight, because the metric ahead cannot be created without tachyonic matter; the same effect can be had without tachyons only by placing devices along the way in advance. Coule: the Alcubierre spacetime is impossible to set up without first distributing matter at tachyonic speed, "you need one to make one"

## What it forbids or costs

"Just build a warp drive" is not a plan. Warp travel is infrastructure, like a railway, laid at sublight speed

## Escape hatches

The Krasnikov tube (CON-3), which accepts this and makes the return trip fast. Coule allows that over small distances, where the energy conditions can perhaps be violated, one might open the light cones locally
