# Theories

One dossier per proposal. `physics/` holds real proposals from the literature,
`fiction/` holds invented drives from books, film, television and games. Each
directory has its own TEMPLATE.md; the two share the loophole classes and the
register, and differ in everything else.

[CATALOGUE.md](CATALOGUE.md) is the hand-written worklist: what should exist,
by loophole. The generated [INDEX.md](../INDEX.md) at the repo root lists what
does.
